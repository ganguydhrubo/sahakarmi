Questions

Is Sahkarmi really free?

Yes. Sahkarmi is free and open source under the Apache 2.0 license. It comes with free built-in AI, needs no account and no card, and has no in-app purchases.

Microsoft Store or the installer: which should I pick?

The Microsoft Store version is signed by Microsoft, installs without any warning and updates itself. The .exe installer is the same app; Windows may warn because it is not code-signed yet, and it updates itself too.

Windows says it protected my PC. What do I do?

Choose More info, then Run anyway. The warning appears because the installer is not code-signed yet. If your PC uses Smart App Control, which blocks unsigned apps, install from the Microsoft Store instead.

Can I use Sahkarmi on my phone?

Sahkarmi installs on a Windows PC. Since version 0.33 you can then approve requests, chat with coworkers and run routines from your iPhone or Android through your own free Tailscale, with Settings, Phone and Host.

Does it work on Mac or Linux?

Not yet. The macOS and Linux builds are paused while the Windows app is finished. You can build from source on any platform with Bun and Node.js.
