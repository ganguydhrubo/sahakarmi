Free and open source

A free, open-source AI agent for your Windows PC

Sahkarmi is an open-source desktop AI agent app under the Apache License 2.0. All of its source code is public, every installer is built from that code by GitHub Actions, and it costs nothing to download or use. This page explains what is open, how to check a download, and how Sahkarmi differs from other kinds of AI agents.

What is open

  • The whole app. The desktop app, the coworker engine, the browser and desktop tools and the website are in one public repository: github.com/ganguydhrubo/sahakarmi.
  • The licence. Apache 2.0: use it at home or at work, change it and redistribute it, including commercially, under the licence's terms.
  • The builds. Releases are built in public GitHub Actions runs. Each release lists SHA-256 checksums and a software bill of materials (SPDX), and carries a GitHub build provenance attestation that links the installer to the commit and workflow that produced it.
  • No telemetry. The app sends no analytics. Its own network traffic is the update check against GitHub Releases; everything else goes to the AI provider and the websites you use. See the privacy policy.

Check a download

Compare the installer's SHA-256 with the one on the release page and on the download section. In PowerShell:

Get-FileHash .\Sahkarmi-0.22.0-x64.exe -Algorithm SHA256

The current installer's SHA-256 is f26bcb4502308f2803b6c83e00f23e1b77dcfb7e449b87b0064b6fe8faa9999b. With the GitHub CLI you can also check the provenance attestation:

gh attestation verify .\Sahkarmi-0.22.0-x64.exe --repo ganguydhrubo/sahakarmi

The installer is not code-signed yet, so Windows SmartScreen warns on first run. The Microsoft Store version is signed by Microsoft and installs without the warning. More in the install guide.

Sahkarmi's trade-offs: it is Windows-only for now, it is a development preview, and the quality of each task depends on the AI model you connect. It has not been evaluated on computer-use benchmarks, so it makes no score claims.

What it costs

The app is free, with no account, subscription, ads or in-app purchases. Free AI models are built in through the bundled OpenCode runtime, which sets usage limits on its free models. If you connect a paid provider (Claude, ChatGPT, Gemini and others), that provider's plan and limits apply and it bills you directly. The savings calculator helps decide whether a paid plan is worth it for you.

Contribute

Bug reports, translations and code are welcome. Read CONTRIBUTING.md, open an issue, or report a security problem privately as described in SECURITY.md.

Questions

Is Sahkarmi really free?

Yes. The app is free and open source under the Apache License 2.0, with no account, subscription or in-app purchases. Paid AI providers you choose to connect bill you directly.

Can I use it at work?

Yes. The Apache 2.0 licence allows commercial use. Check your company's rules about which AI providers may see work data, because the coworkers send what they read to the provider you choose.

Can I build it myself?

Yes. The repository's README has the build steps (Bun and Node.js). The released installers are built from the same source in public GitHub Actions runs.

Does it work on macOS or Linux?

Not yet. Windows 10 and 11 (64-bit) is the released and tested build; macOS and Linux builds are paused until they can be tested on real hardware.
