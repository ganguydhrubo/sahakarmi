A free AI agent for Windows 11 and Windows 10

Sahkarmi is a desktop AI agent app built for Windows. Install it like any other program, pick a free or paid AI, and give its coworkers tasks that run on your PC: in their own browsers, in your files and, if you allow it, in your Windows apps.

Requirements

  • Windows 10 or Windows 11, 64-bit (x64). Windows on ARM and 32-bit Windows are not supported.
  • About 1 GB of disk for the app and its AI runtime; on the project's test PC (16 GB RAM) it used about 1 GB of memory while working.
  • An internet connection: the AI models run at the provider you choose, including the free built-in ones.
  • No account with Sahkarmi. No admin rights for the installer.

What it does in Windows

  • Uses your desktop apps

    With the Control this PC permission a coworker can start apps, switch windows, read a window's buttons and fields through Windows UI Automation, click, scroll, drag, type and press shortcuts. Details

  • Has its own browser

    Each coworker browses in its own profile and stays signed in to its own accounts, separate from Edge, Chrome and the other coworkers.

  • Works in folders

    Each coworker has a working folder, and the team shares one Shared folder. Knowledge bases index your documents on this PC.

  • Runs on a schedule

    Routines run hourly, daily, on weekdays or weekly while Sahkarmi is open.

  • Asks first

    Posting, sending, submitting and paying wait for your approval in the app or on Telegram.

  • Speaks your language

    English, हिन्दी and বাংলা, with more Indian languages partly translated.

The first ten minutes

  1. Install and open Sahkarmi. Keep OpenCode (free, built in) selected, or connect Claude, ChatGPT (Codex) or Google Gemini (Antigravity) in Settings, AI and models.
  2. Open a coworker from the list on the left, for example the research coworker, and type a small task: “Find three free project-management tools and compare their limits in a table.”
  3. Watch its browser on the right. Use Take over if it needs you to sign in somewhere.
  4. To let it work in desktop apps, set Settings, Permissions, Control this PC to ask (the default) and approve its first desktop step.
  5. Answer approval cards as they come. Then try a routine: “Every weekday at 9, …”.

Update and uninstall

The installer version checks GitHub Releases and updates in place, keeping your coworkers, chats and sign-ins; the Store version updates through the Store. Uninstall from Settings, Apps; the uninstaller asks whether to delete your Sahkarmi data too, and keeps it unless you say yes.

Questions

Is there a free AI agent for Windows 11?

Yes. Sahkarmi is free and open source (Apache 2.0) and runs on Windows 11 and Windows 10, 64-bit. It includes free AI models, so you can use it without a paid AI subscription.

Does it need administrator rights?

No. The installer installs for the current user only. The Microsoft Store version installs the usual Store way.

Can it use apps like Excel or a desktop accounting program?

With the Control this PC permission a coworker can operate Windows apps through their buttons, menus and fields, or by screenshot and position. How reliably it completes a task depends on the app and on the AI model you connect, so start small and check the result.

Why does Windows SmartScreen warn about the installer?

The .exe is not code-signed yet, so SmartScreen does not recognise it. Choose More info, then Run anyway, or install the Microsoft Store version, which is signed by Microsoft.
