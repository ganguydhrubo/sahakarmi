AI DevOps & Release Manager

Sets up CI, builds and deploys, prepares releases with rollback plans and checks the live site after.

Role: CI/CD, hosting and releases · Ready to use with Sahkarmi's built-in tools.

Example: a first task

Put the repository, and the hosting target (Vercel, Netlify, a VPS, app store) in Shared/Engineering/Releases, then ask in plain words for a working CI pipeline; a release checklist with rollback plan and a post-deploy check report with URLs. Start with one small, real piece of work and check what comes back.

What the AI DevOps & Release Manager covers

DevOps engineer · release manager · CI/CD · GitHub Actions · Docker · Vercel deploy · VPS setup · site reliability · uptime monitoring

What the AI DevOps & Release Manager needs from you

Needs

  • The repository.
  • The hosting target (Vercel, Netlify, a VPS, app store).

Helpful

  • Domain and DNS provider.
  • Environment variable names (not values).
  • Monitoring tool.

How the AI DevOps & Release Manager works

  1. Read the build and deploy setup and reproduce the build locally.
  2. Add or fix CI (install, lint, test, build) and preview deploys.
  3. Prepare the release: version bump, changelog, env checklist, migration order and rollback steps.
  4. After approval, deploy, then check the live URL, logs and key pages; roll back if checks fail.

What you get from the AI DevOps & Release Manager

  • A working CI pipeline.
  • A release checklist with rollback plan.
  • A post-deploy check report with URLs.

Everything is saved in Shared/Engineering/Releases on your computer.

Checks before it reports done

  • CI passes on the release commit.
  • Rollback steps tested or clearly documented.
  • Live checks recorded with status codes.

Done when: the release is live and verified, or rolled back with the reason recorded.

Asks your approval before

  • Deploying to production.
  • Changing DNS or domains.
  • Changing production environment variables.
  • Upgrading paid plans.

Each request appears as an approval card in Sahkarmi (and in Telegram, if you connect it).

Tools and services

  • Files in its folder and Shared.
  • Code and commands on your PC (per your permissions).
  • Sahkarmi's built-in browser, signed in by you.
  • Scheduled runs.

Services

  • GitHub Actions: in Sahkarmi's browser, with your own sign-in.
  • Vercel, Netlify, Cloudflare or VPS panel: in Sahkarmi's browser, with your own sign-in; owner signs in; production changes need approval.

Add the AI DevOps & Release Manager

In Sahkarmi, open Marketplace, search for “DevOps & Release Manager” and click Add. New to Sahkarmi? The install guide takes a few minutes.

Questions

Is the AI DevOps & Release Manager free?

Yes. The AI DevOps & Release Manager comes free with Sahkarmi, which is open source (Apache 2.0) and needs no account. It runs on the free built-in AI or on your own Claude, ChatGPT or Gemini plan.

What does the AI DevOps & Release Manager need from me?

The repository and the hosting target (Vercel, Netlify, a VPS, app store). It also helps to have domain and DNS provider; environment variable names (not values) and monitoring tool.

Does the AI DevOps & Release Manager act without asking me?

It is set up to ask for your approval before deploying to production; changing DNS or domains; changing production environment variables and upgrading paid plans. Each request shows as an approval card you accept or reject.

Where does the AI DevOps & Release Manager keep my files?

On your own computer, in Shared/Engineering/Releases. Sahkarmi has no cloud account; your files go only to the AI provider you choose, as part of the task.

Sahkarmi is free and open source (Apache 2.0). No account, no card. Windows 10 and 11, 64-bit.
