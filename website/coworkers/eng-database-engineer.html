AI Database Engineer

Designs schemas, writes safe migrations and speeds up slow queries in Postgres, MySQL or SQLite.

Role: Schemas, migrations and queries · Ready to use with Sahkarmi's built-in tools.

AI Database Engineer is one of 175 ready-made coworkers in Sahkarmi, a free desktop app that gives you a team of AI coworkers on your own Windows PC. How well a task goes depends on the AI model and the sites or files involved; start with a small task and check the result.

What it covers

database developer · DBA · SQL · PostgreSQL · MySQL · schema design · data migration · query optimisation · Supabase

What you give it

Needs

  • The data to store or the slow query.
  • The repository or a schema dump.

Helpful

  • Row counts.
  • EXPLAIN output.
  • Backup policy.

How it works

It restates the goal in one line, looks in the chat and the Shared folder for what it needs before asking you, and lists its plan. Then:

  1. Read the current schema and how the code uses it.
  2. Design tables, keys, constraints and indexes; write forward and rollback migrations.
  3. Test migrations on a local copy with sample data and compare query plans before and after.
  4. Write a runbook for applying the migration in production.

Finally it runs its checks and reports what was done, the evidence and what is still open.

What you get

  • Migration files with rollback.
  • A schema diagram.
  • A migration runbook.

Everything is saved in Shared/Engineering/Database on your computer.

Checks before it reports done

  • Migration and rollback both run on a local copy.
  • No data loss on sample data.
  • Query timings before and after recorded.

Done when: migrations are tested locally and the runbook is ready for an approved production run.

Asks your approval before

  • Running any migration on production.
  • Deleting or truncating data.

Each request appears as an approval card in Sahkarmi (and in Telegram, if you connect it).

Tools and services

  • Files in its folder and Shared.
  • Code and commands on your PC (per your permissions).
  • Spreadsheets (CSV, Excel, Sheets exports).

Add it in four steps

  1. Download and install Sahkarmi for Windows (free, no account). The install guide covers every step.
  2. Pick an AI: the free built-in models, or connect Claude, ChatGPT or Gemini in Settings, AI and models.
  3. Open Marketplace, search for “Database Engineer” and click Add.
  4. Give it one small task in plain words, in English, Hindi or Bengali, and approve or reject each card.

Questions

Is the AI Database Engineer free?

Yes. Sahkarmi and all its ready-made coworkers are free and open source (Apache 2.0), with no account or subscription. Coworkers run on the free built-in AI models, or on a Claude, ChatGPT or Gemini account you connect; paid plans are billed by those providers, not by Sahkarmi.

What does the AI Database Engineer need from me?

The data to store or the slow query and the repository or a schema dump. It also helps to have row counts; EXPLAIN output and backup policy.

Does the AI Database Engineer act without asking me?

It is set up to ask for your approval before running any migration on production and deleting or truncating data. Each request shows as an approval card you accept or reject.

Where does the AI Database Engineer keep my files?

On your own computer, in Shared/Engineering/Database. Sahkarmi has no cloud account; your files go only to the AI provider you choose, as part of the task.

Sahkarmi is free and open source (Apache 2.0). No account, no card. Windows 10 and 11, 64-bit.
