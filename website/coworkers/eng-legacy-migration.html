AI Legacy Code & Migration Analyst

Maps an old codebase, plans upgrades or rewrites (PHP, jQuery, old Node, VB/Access apps) and migrates in safe steps.

Role: Legacy code and upgrades · Ready to use with Sahkarmi's built-in tools.

AI Legacy Code & Migration Analyst is one of 175 ready-made coworkers in Sahkarmi, a free desktop app that gives you a team of AI coworkers on your own Windows PC. How well a task goes depends on the AI model and the sites or files involved; start with a small task and check the result.

What it covers

legacy code · code modernisation · framework upgrade · PHP to Node · jQuery to React · migration plan · technical debt · codebase documentation

What you give it

Needs

  • The existing codebase or app.
  • The target (version, framework or platform).

Helpful

  • Why the migration is needed.
  • A database copy.
  • Who uses the system today.

How it works

It restates the goal in one line, looks in the chat and the Shared folder for what it needs before asking you, and lists its plan. Then:

  1. Inventory the code: modules, dependencies and versions, dead code and business rules buried in it.
  2. Add characterisation tests around critical behaviour before changing anything.
  3. Plan the migration in reversible steps with effort and risk per step.
  4. Carry out the first steps on a branch and compare behaviour against the tests.

Finally it runs its checks and reports what was done, the evidence and what is still open.

What you get

  • A codebase map with business rules.
  • A step-by-step migration plan.
  • Migrated code on a branch with test results.

Everything is saved in Shared/Engineering/Migration on your computer.

Checks before it reports done

  • Characterisation tests pass before and after each step.
  • Every business rule found is listed.
  • No step removes behaviour silently.

Done when: the map and plan are saved and completed steps pass their tests.

Asks your approval before

  • Switching users to the migrated system.
  • Deleting the old code or data.

Each request appears as an approval card in Sahkarmi (and in Telegram, if you connect it).

Tools and services

  • Files in its folder and Shared.
  • Code and commands on your PC (per your permissions).
  • Word, PDF and Markdown documents.

Add it in four steps

  1. Download and install Sahkarmi for Windows (free, no account). The install guide covers every step.
  2. Pick an AI: the free built-in models, or connect Claude, ChatGPT or Gemini in Settings, AI and models.
  3. Open Marketplace, search for “Legacy Code & Migration Analyst” and click Add.
  4. Give it one small task in plain words, in English, Hindi or Bengali, and approve or reject each card.

Questions

Is the AI Legacy Code & Migration Analyst free?

Yes. Sahkarmi and all its ready-made coworkers are free and open source (Apache 2.0), with no account or subscription. Coworkers run on the free built-in AI models, or on a Claude, ChatGPT or Gemini account you connect; paid plans are billed by those providers, not by Sahkarmi.

What does the AI Legacy Code & Migration Analyst need from me?

The existing codebase or app and the target (version, framework or platform). It also helps to have why the migration is needed; a database copy and who uses the system today.

Does the AI Legacy Code & Migration Analyst act without asking me?

It is set up to ask for your approval before switching users to the migrated system and deleting the old code or data. Each request shows as an approval card you accept or reject.

Where does the AI Legacy Code & Migration Analyst keep my files?

On your own computer, in Shared/Engineering/Migration. Sahkarmi has no cloud account; your files go only to the AI provider you choose, as part of the task.

Sahkarmi is free and open source (Apache 2.0). No account, no card. Windows 10 and 11, 64-bit.
