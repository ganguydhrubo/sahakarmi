Coworkers

AI coworkers for software & it

Coding, bug fixing, code review, testing, DevOps and documentation, run in a project folder you choose. 15 ready-made coworkers, free in Sahkarmi for Windows.

  • AI Software Engineering Team

    Runs a software task end to end: plans it, assembles only the specialists it needs, splits work without conflicts, integrates, tests and ships after approval.

  • AI Technical Lead & Architect

    Chooses the stack and architecture, writes design docs and decision records, and breaks work into safe tasks.

  • AI Product Requirements Analyst

    Turns an idea or client brief into a PRD with user stories, acceptance criteria and a scoped MVP.

  • AI Frontend Engineer

    Builds responsive, accessible UI in React, Next.js, Vue or plain HTML, and checks it in the browser.

  • AI Backend & API Engineer

    Builds APIs, background jobs and third-party integrations (Razorpay, WhatsApp, Tally exports) with tests.

  • AI Full-Stack Engineer

    Builds small apps and internal tools end to end: UI, API, database and a preview deploy.

  • AI Database Engineer

    Designs schemas, writes safe migrations and speeds up slow queries in Postgres, MySQL or SQLite.

  • AI QA & Test Automation Engineer

    Writes test plans and automated tests (unit, API, Playwright end-to-end) and reports bugs with repro steps.

  • AI Security Review Assistant

    Reviews code and configuration against OWASP Top 10, scans dependencies and secrets, and lists fixes by risk.

  • AI DevOps & Release Manager

    Sets up CI, builds and deploys, prepares releases with rollback plans and checks the live site after.

  • AI Bug Investigator

    Reproduces a reported bug, finds the root cause and proposes a tested fix.

  • AI Code Reviewer

    Reviews pull requests for correctness, readability, tests and risk, and writes clear review comments.

  • AI Legacy Code & Migration Analyst

    Maps an old codebase, plans upgrades or rewrites (PHP, jQuery, old Node, VB/Access apps) and migrates in safe steps.

  • AI Developer Support

    Sets up dev environments, fixes install and build errors, and explains code or tools step by step.

  • AI Technical Documentation Engineer

    Writes READMEs, API references, setup guides and user manuals from the actual code.

Questions

Are these software & it coworkers free?

Yes. Sahkarmi and all its ready-made coworkers are free and open source (Apache 2.0), with no account or subscription. Coworkers run on the free built-in AI models, or on a Claude, ChatGPT or Gemini account you connect; paid plans are billed by those providers, not by Sahkarmi.

Can several coworkers work together?

Yes. Each coworker has its own chat, folder, browser and task queue, and coworkers can hand work to each other. A team run splits one goal into tasks for several coworkers.

Sahkarmi is free and open source (Apache 2.0). No account, no card. Windows 10 and 11, 64-bit.
