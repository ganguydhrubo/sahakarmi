AI Bug Investigator

Reproduces a reported bug, finds the root cause and proposes a tested fix.

Role: Debugging and root cause · Ready to use with Sahkarmi's built-in tools.

Example: a first task

Put the bug report (what happened, where, when), and the repository in Shared/Engineering/Bugs, then ask in plain words for a root-cause note; a fix branch with a regression test and test output. Start with one small, real piece of work and check what comes back.

What the AI Bug Investigator covers

debugging · bug fixing · root cause analysis · production issue · error logs · crash investigation · support engineer

What the AI Bug Investigator needs from you

Needs

  • The bug report (what happened, where, when).
  • The repository.

Helpful

  • Logs or screenshots.
  • The user's device and browser.
  • The last working version.

How the AI Bug Investigator works

  1. Reproduce the bug locally or in the browser and write down exact steps.
  2. Narrow the cause with logs, breakpoints or git bisect.
  3. Write a failing test, then the smallest fix that makes it pass.
  4. Run the full suite and explain the cause and fix in plain language.

What you get from the AI Bug Investigator

  • A root-cause note.
  • A fix branch with a regression test.
  • Test output.

Everything is saved in Shared/Engineering/Bugs on your computer.

Checks before it reports done

  • The new test fails before the fix and passes after.
  • The full suite still passes.
  • The root cause is shown, not guessed.

Done when: the bug is reproduced, fixed with a test, or documented as not reproducible with what was tried.

Asks your approval before

  • Merging to main.
  • Deploying a hotfix to production.

Each request appears as an approval card in Sahkarmi (and in Telegram, if you connect it).

Tools and services

  • Files in its folder and Shared.
  • Code and commands on your PC (per your permissions).
  • Sahkarmi's built-in browser, signed in by you.

Add the AI Bug Investigator

In Sahkarmi, open Marketplace, search for “Bug Investigator” and click Add. New to Sahkarmi? The install guide takes a few minutes.

Questions

Is the AI Bug Investigator free?

Yes. The AI Bug Investigator comes free with Sahkarmi, which is open source (Apache 2.0) and needs no account. It runs on the free built-in AI or on your own Claude, ChatGPT or Gemini plan.

What does the AI Bug Investigator need from me?

The bug report (what happened, where, when) and the repository. It also helps to have logs or screenshots; the user's device and browser and the last working version.

Does the AI Bug Investigator act without asking me?

It is set up to ask for your approval before merging to main and deploying a hotfix to production. Each request shows as an approval card you accept or reject.

Where does the AI Bug Investigator keep my files?

On your own computer, in Shared/Engineering/Bugs. Sahkarmi has no cloud account; your files go only to the AI provider you choose, as part of the task.

Sahkarmi is free and open source (Apache 2.0). No account, no card. Windows 10 and 11, 64-bit.
