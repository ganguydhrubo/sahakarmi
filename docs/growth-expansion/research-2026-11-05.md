# Sahkarmi growth research: search demand, competitors, benchmarks, distribution

Date: 2026-11-05. Scope: web research only. No paid SEO tools were used.

## How the evidence was gathered (read this first)

- **Autocomplete (AC):** real Google suggestions fetched from `https://suggestqueries.google.com/complete/search?client=firefox&hl=en&gl=us&q=...` on 2026-11-05. "AC hit" means the exact query (or a very close variant) came back as a Google suggestion. That shows people search for it. It does **not** show how many people do.
- **SERP:** the results come from the research tool's web search (a US index). That is **not** a Google results page, so "who ranks" is an approximation. Each such note is marked "observed in SERP on 2026-11-05".
- **Volumes:** no volume data for any query. No figures were made up.
- **Feasibility** means how realistic it is for sahkarmi.site to reach page one in the next 3-6 months. It is a judgement call based on who ranks now: low means big brands, vendor docs or large media hold the results; high means thin listicles, aggregators or almost nothing on topic.
- **Existing site pages** (from https://sahkarmi.site/sitemap.xml, fetched 2026-11-05): `/`, `/install.html`, `/docs.html`, `/savings.html`, `/changelog.html`, `/privacy.html`, `/terms.html`. New pages proposed below are chosen so they do not compete with these.

### Two brand findings that matter before any SEO work

1. A web search for "Sahkarmi AI coworkers Windows" returned **no Sahkarmi results**. It returned only general "AI coworker" pages (observed in SERP on 2026-11-05). The brand is not yet visible in that index. Branded searches cannot carry downloads yet.
2. **Name collision on GitHub.** A repo search for "sahkarmi" returns `sukumarsaurav/SahkarmiAi` (created 2025-01-24, empty description) and `SahkarmiAI/sahkarmi-website` ("Sahkarmi marketing website", created 2026-10-24), alongside `ganguydhrubo/sahakarmi` and `ganguydhrubo/scoop-sahkarmi` (GitHub API, 2026-11-05). The owner should confirm whether `SahkarmiAI` belongs to them. Also note that the repo name `sahakarmi` and the brand `Sahkarmi` are spelled differently, which splits brand searches. The main repo had **1 star and 0 forks** on 2026-11-05 (GitHub API). That limits awesome-lists that require traction.

## 3. Benchmarks (context only: **Sahkarmi has NOT been evaluated on any of them**)

**OSWorld / OSWorld-Verified.** OSWorld (NeurIPS 2024) is a benchmark of 369 open-ended computer tasks in real desktop environments (Ubuntu, with Windows/macOS support in the framework). It covers real web and desktop apps, OS file I/O and multi-app workflows, scored by execution-based evaluation scripts. In the paper, humans completed over 72.36% of tasks and the best model 12.24% ([arXiv 2404.07972](https://arxiv.org/abs/2404.07972)). "OSWorld-Verified" was announced 2025-07-28: fixed community-reported tasks, AWS parallel evaluation within about 1 hour, and refreshed results. It can run all 369 tasks or 361 without the Google-Drive tasks ([github.com/xlang-ai/OSWorld](https://github.com/xlang-ai/OSWorld), [os-world.github.io](https://os-world.github.io)). Leaderboards warn that self-reported rows use different step budgets and images, so scores are not always comparable ([leaderboard.steel.dev](https://leaderboard.steel.dev/leaderboards/osworld.md)).

**WebArena.** A self-hosted, reproducible web environment with functional sites across four domains: e-commerce, social forums, collaborative software development and content management. It tests long-horizon, realistic tasks with functional-correctness checks. The best GPT-4 agent reached 14.41% end-to-end success against 78.24% for humans ([arXiv 2307.13854](https://arxiv.org/abs/2307.13854)). Related projects from the same group: VisualWebArena (multimodal), WebArena-Infinity, TheAgentCompany ([webarena.dev](https://webarena.dev/)).

**WebVoyager.** Tests end-to-end web agents on **live** websites: real tasks from 15 popular sites (643 tasks are commonly cited). Scoring is done by a GPT-4V-based automatic evaluator that agreed with humans 85.3% of the time. The original agent scored 59.1% ([arXiv 2401.13919](https://arxiv.org/abs/2401.13919)). Because the sites are live, results drift over time; critics note the task set is limited and skewed toward easier tasks ([arXiv 2504.01382](https://arxiv.org/pdf/2504.01382), [steel.dev](https://leaderboard.steel.dev/leaderboards/webvoyager.md)).

**Windows Agent Arena (WAA).** Microsoft's Windows OS benchmark, built on the OSWorld framework. It has 154 tasks across Office/documents, spreadsheets, Edge/Chrome browsing, File Explorer, Settings, VS Code, VLC, Notepad and Paint. It runs in parallel on Azure (about 20 minutes for a full run). The baseline agent "Navi" scored 19.5% against 74.5% for humans ([arXiv 2409.08264](https://arxiv.org/pdf/2409.08264), [microsoft.github.io/WindowsAgentArena](https://microsoft.github.io/WindowsAgentArena)). This is the closest fit to Sahkarmi's Windows positioning. Running WAA would be the only credible way to make any accuracy claim.

Guidance: site copy must not claim benchmark scores. A benchmarks explainer page (#9 above) is fine if it says plainly that Sahkarmi is not evaluated and that results depend on the underlying model and provider.
