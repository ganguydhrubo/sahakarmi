# Sahkarmi competitive landscape — research report (observed 2026-10-24)

Method: primary sources only (official sites, GitHub repo pages/REST API, raw LICENSE files, /releases/latest, docs, pricing/terms pages). Four parallel research threads plus direct verification of the owner-named "OpenBot", the adjacent "AI cowork desktop" category, and Indian SMB agent vendors. GitHub release pages omit the year; where a year is given it comes from the GitHub API `published_at` or from release ordering. Anything not verifiable is called out explicitly in section (f).

## 0. Headline findings (things that differ from the owner's assumptions)

1. **"OpenBot" is real and is the closest direct competitor: `nightly-labs/openbot` (openbot.run), by Synthetify Labs sp. z o.o. (Poland).** PolyForm Noncommercial 1.0.0 (LICENSE file title verified), "Versions up to and including 0.1.11 remain available under Apache-2.0" (README), latest v0.48.2 released 23 Oct 2026 — ten releases in the five days 19–23 Oct. 820 stars / 130 forks / 97 open issues / 2,031 commits. README: Gemini "downloads Google's Antigravity ACP server on this computer"; agents run with "`danger-full-access` and `approvalPolicy: never`"; UI in English, French, Japanese, Brazilian Portuguese, Turkish (no Indic). Do not confuse with `CopilotKit/OpenBot` (MIT, 7.0k stars, Docker "template, not a product", AG-UI) or Intel's robotics OpenBot.
2. **The owner's list misses the category Sahkarmi actually sits in — "open-source Claude Cowork alternatives".** OpenWork (different-ai, 24.2k stars, MIT + EE), OpenWorker (Andrew Ng, 18.7k, MIT, Tauri, approvals-by-default), Eigent (15.7k, Apache-2.0, Electron, scheduled automations), Paseo (21.8k, Apache-2.0, orchestrates Claude Code/Codex/OpenCode/Antigravity), Open Cowork (2.2k, MIT), Coworker/Accomplish (10.8k, now "no longer supported"). These are the real peer set.
3. **OpenClaw exists and is the largest repo in the whole landscape:** `openclaw/openclaw`, 392,896 stars, MIT, v2026.10.6 (22 Oct 2026); formerly Clawdbot → Moltbot. The "OPENCLAW-style state env vars" are real: `OPENCLAW_HOME`, `OPENCLAW_STATE_DIR` (default `~/.openclaw`), `OPENCLAW_CONFIG_PATH`, `OPENCLAW_PROFILE`, `OPENCLAW_WORKSPACE_DIR` (docs.openclaw.ai/help/environment).
4. **Two legal/ToS risks for Sahkarmi's "reuse local sign-ins" feature, P0:**
   - **Antigravity Terms §6:** "Using third party software, tools, or services to access the Service (e.g. using OpenClaw with Antigravity OAuth) is a breach of this Agreement… may be grounds for suspension or termination" (antigravity.google/terms). The ACP server (`agy_acp_server.par`/`.exe` v1.4.3) is in the ACP registry with license "proprietary". OpenBot does exactly this today; that does not make it permitted.
   - **Anthropic:** "Unless previously approved, Anthropic does not allow third party developers to offer claude.ai login or rate limits for their products" (Agent SDK docs); permitted path is the **unmodified** `claude` binary with Anthropic's own OAuth flow, never reading `~/.claude` tokens, and no "Claude Code" branding (code.claude.com/docs/en/legal-and-compliance). OpenCode removed its Claude Pro/Max OAuth plugins at 1.3.0 because "Anthropic explicitly prohibits this" (opencode.ai/docs/providers). Codex/ChatGPT OAuth reuse: no published prohibition found (absence, not permission).
5. **Sahkarmi's bundled OpenCode free models are not business-data-safe by default:** opencode.ai/docs/zen lists free models as "available for a limited time", some "may use collected data to improve the model", Nemotron entries say "Trial use only — do not submit personal or confidential data", and "free-tier chat models require OpenCode and can't be used from other clients".
6. **Market shifts since mid-2026:** Gemini CLI free/Pro/Ultra tiers withdrawn 18 Jun 2026 in favour of Antigravity CLI `agy`; OpenCode moved `sst/opencode` → `anomalyco/opencode` (220,716 stars); OpenHands repo is now `OpenHands/OpenHands` and rebranded "Agent Canvas"; Goose moved to `aaif-goose/goose` (Linux Foundation AAIF); Roo Code shut down 15 May 2026 (archived); Cursor acquired by SpaceX (14 Aug 2026) with an India-only ₹649/month "Cursor Start" plan; Anthropic merged Cowork into Claude (16 Sep 2026) and made Pro/Max Cowork cloud-only (6 Oct 2026); OpenAI merged the Codex app into the ChatGPT desktop app (Jul 2026).
7. **Nobody in the ~35 products targets non-developer Indian SMBs with a desktop agent.** Hindi UI exists in Jan, Open WebUI, AnythingLLM, ChatGPT, Claude; Bengali UI only in Open WebUI and ChatGPT. The Indian SMB agent market is WhatsApp-first and cloud (Haptik/Interakt, Meta Business AI, Zoho Zia, Sahayak AI); the only "desktop" artefacts are Tally MCP servers for Claude/ChatGPT Desktop.

## (b) Per-product notes with citations

### 1. OpenBot (nightly-labs/openbot) — the owner's "OpenBot"
- URLs: https://github.com/nightly-labs/openbot, https://openbot.run, releases https://github.com/nightly-labs/openbot/releases (all 2026-10-24).
- JTBD: "A local-first desktop workspace for persistent AI teammates" (repo description); "Run a team of AI agents on your computer" (site).
- Audience — stated: individuals with existing AI plans; companies via "OpenBot for Teams" ("AI coworkers for your whole company", managed servers, implementation support). Observed: Electron/SolidJS/Bun/TypeScript topics, Codex-centric, developer-heavy release notes; 130 forks but only 820 stars after ~48 minor versions.
- OS/install: macOS 13+ DMG (notarized), Windows 10+ x64 "NSIS `.exe` installer… signed by SYNTHETIFY LABS; older releases are not code-signed" (README), Linux AppImage x64/arm64 (AppArmor note for Ubuntu 23.10+), `nix run github:nightly-labs/openbot`, Docker `ghcr.io/nightly-labs/openbot`, headless Ubuntu install script, iPhone TestFlight, Android Play (`run.openbot.mobile`), web client openbot.run/app. Dev needs Bun 1.4.2 + Node 24.
- Models/auth: "local Codex App Server process over stdio JSONL"; Claude Code via "existing local CLI login. It does not copy provider credentials"; Grok CLI; "OpenCode, Gemini, Cursor CLI, and Cline CLI through ACP"; custom OpenAI-compatible endpoints and custom ACP agents; Ollama/LM Studio detection. Gemini: "Gemini uses a Google AI Pro or Ultra plan… downloads Google's Antigravity ACP server on this computer… OpenBot never uses an `antigravity` command on your search path" (README); provider page: "downloads and pins its own copy of Google's Antigravity agent server" and notes "On 18 June 2026, Gemini CLI stopped serving Google AI Pro, Ultra and free accounts" (openbot.run/providers/gemini). "OpenCode's free models need no account and no sign-in."
- Features ("What works"): prompt-driven agent creation; persistent agents with independent sessions and local workspaces; per-agent context monitoring with auto-compaction; FIFO message queues with pause/resume/cancel, crash-safe; agent-to-agent messages/reactions/file transfers; shared channel chats with one task owner; persistent embedded browser agents "open, inspect, and control"; optional Computer Use via `cua-driver` binary; per-agent model/reasoning settings; skills library; "channel memories and routines"; webhooks for routines; team catalog/marketplace; optional accounts via one-time email codes; hosted servers with Stripe plan catalog (code present, no prices).
- Limitations: "OpenBot is a development preview"; "Agents currently run with `danger-full-access` and `approvalPolicy: never`… without per-action confirmations after the explicit first-launch consent" (README); site safety note: agents "control the browser without asking each time"; no "take over" wording anywhere; i18n limited to en/fr/ja/pt-BR/tr; CLA assigns copyright to Synthetify Labs; Discussions tab, no Discord link.
- License: LICENSE title "PolyForm Noncommercial License 1.0.0", "Copyright 2026 Synthetify Labs spółka z ograniczoną odpowiedzialnością"; README: "Commercial use requires a separate license… licenses@openbot.run… Versions up to and including 0.1.11 remain available under Apache-2.0." Site: "not an open-source license as the OSI defines one."
- Stars/release: 820 stars, 130 forks, 5 watchers, 97 open issues, 23 PRs, 2,031 commits; v0.48.2 (23 Oct), v0.48.1/0.48.0 (22 Oct), v0.47.x (21 Oct), v0.46.0/0.45.0 (20 Oct), v0.44.1–3 (19 Oct); 33 assets per release; release notes mention ACP ("Give ACP agents MCP server names they accept"; "Offer Oh My Pi as a known custom ACP agent").
- Onboarding (site): download → connect provider → describe agent in one prompt → check instructions and save → send work.
- Pricing: "$0… No hidden fees. No locked features"; Teams custom.
- Lessons: (1) OpenBot is Sahkarmi's architecture (Electron+SolidJS, local-first, Codex App Server + Claude Code login + Antigravity ACP + OpenCode free models) already shipping fast, but with no approvals, no business framing, no Indic UI and a non-OSI license — Sahkarmi's Apache-2.0 + approvals-by-default + Hindi/Bengali is a clean counter-position. (2) Their Apache→PolyForm relicense at 0.1.12 is a cautionary tale: Sahkarmi should state a license-stability promise.

### 1b. CopilotKit/OpenBot
- https://github.com/CopilotKit/openbot: MIT, 7.0k stars, 958 forks, 562 commits, no releases shown. "A template, not a product"; "Alpha." Docker Compose, Bun 1.3+, PostgreSQL, needs CopilotKit Intelligence project + OpenAI key. Each Bot gets its own Chromium + `/workspace`; CEL policy gateway ("deny checked before allow, missing policy permits nothing"); "a Bot can ask for help at logins or 2FA prompts, and a person can take control"; audit log; routines ≥15 min; SSO (Google/Microsoft/Okta/SAML). Lesson: the only product besides ChatGPT with explicit human take-over at login/2FA, and a strong policy/audit model — but server-side; Sahkarmi can borrow the "every action decided before it happens and recorded after" framing.

### 2. OpenAI — Codex CLI / ChatGPT desktop + Agent mode
(Note: openai.com, chatgpt.com, help.openai.com returned HTTP 403 to direct fetches; four pages were proxy-rendered; all other facts from learn.chatgpt.com/docs and GitHub.)
- Codex CLI: https://github.com/openai/codex, docs https://learn.chatgpt.com/docs (developers.openai.com/codex 308-redirects). "Codex CLI is a coding agent from OpenAI that runs locally on your computer." Apache-2.0 (LICENSE + API spdx). 130,718 stars, 20,615 forks, ~24.3k open issues; latest `rust-v0.164.0` 2026-10-23 (separate `codex-app-server-*` binaries). Install: `curl -fsSL https://chatgpt.com/codex/install.sh | sh`, PowerShell installer, `npm i -g @openai/codex`, `brew install --cask codex`. Windows native sandbox, WSL1 dropped since 0.115. Models gpt-6-astra / gpt-6.1-sol / gpt-6-luna; custom providers must be Responses-API. Auth: "Sign in with ChatGPT for subscription access" or API key; `codex login --device-auth`. Embedding: **Codex App Server** (JSON-RPC over stdio, "recommended for deep integration inside your own product") and `@openai/codex-sdk` / `pip install openai-codex`; no native ACP — adapter is `agentclientprotocol/codex-acp` (Apache-2.0). Pricing: Codex included in Free/Go $8/Plus $20/Pro $100–500/Business $20–25; no India-specific Codex pricing. Not open source: IDE extension, Codex cloud.
- ChatGPT desktop (merged with Codex app Jul 2026; "Choose ChatGPT or Codex" in docs/app.md): macOS DMG, Windows Microsoft Store (`winget install --id 9PLM9XGG6VKS -s msstore`), Linux preview (no computer use). Built-in browser with separate profile, confirms before "submitting information, making a purchase"; Computer Use mac/Win with per-app permission; scheduled tasks. **Agent mode** (help article 11752874, proxy-rendered): cloud virtual browser; "…" menu → **"Take over browser"**; "While you control the browser, screenshots are not captured"; limits Plus 40 / Pro 400 / Business & Enterprise 40 messages per month; paid plans only. Hindi, Bengali, Tamil, Telugu etc. in UI languages (article 8357869). India: ChatGPT Go ₹399/month with UPI (search snippets of 403'd pages; unverified today).
- Lessons: match ChatGPT's "Take over browser" + "no screenshots while you drive" guarantee; sell "unlimited local runs" against the 40-messages/month agent cap.

## (d) Gaps and opportunities for Sahkarmi (evidence-grounded)

1. **Business-action approvals as the headline.** No competitor gates payments or customer messages specifically; the nearest are OpenWorker's "hard floors", Claude's "Allow before delete", ChatGPT's purchase confirmation, Muse's "checks… before sending an email or making a purchase" (US-only). OpenBot and OpenClaw default to full access. Lead with "asks before it pays or messages a customer", and log who approved what.
2. **Embedded browser + human Take-over in a no-Docker Electron app.** Only ChatGPT Agent mode (cloud, 40 msgs/month) and CopilotKit/OpenBot (Docker) document explicit take-over; Agent Zero needs Docker; Claude has no take-over mode; Browser Use has live view only. Match ChatGPT's "no screenshots while you drive" guarantee and document it.
3. **Indic UI as part of a business bundle, not alone.** Hindi exists in Jan/Open WebUI/AnythingLLM/ChatGPT/Claude; Bengali only in Open WebUI/ChatGPT. Differentiate with Hindi/Bengali **plus** Indian workflows: Tally via existing MIT MCP servers, GST invoices (Sahayak charges for this), WhatsApp Business integration (Meta's AI owns replies; Sahkarmi does back-office).
4. **Windows-first distribution is a real edge.** OpenCode: "Windows package managers are not supported"; OpenWorker Windows unsigned/"coming soon"; Goose Windows is a bare zip; LM Studio drops Intel Macs; Agent Zero needs Docker; Meta AI has no Windows app. A signed NSIS installer (and later winget/Microsoft Store like ChatGPT, Claude, Jan) is a differentiator for Indian SMB PCs. Note OpenBot and OpenWork already sign Windows builds — Sahkarmi should too.
5. **Fix the sign-in-reuse legal exposure before marketing it.** Antigravity ToS §6 explicitly bans third-party access; Anthropic bans offering claude.ai login except via the unmodified binary/own OAuth; OpenCode already removed Claude OAuth. Options: ship only Codex (no prohibition found), the unmodified `claude` binary via official ACP adapter, `gemini --acp` with user API key, and Antigravity only with `gemini-api-key`/`agent-platform` auth types or a consent screen quoting §6. Publish a "how we reuse your sign-in" page.
6. **Make the free runtime business-safe.** Pin OpenCode's free-model list, surface retention/training caveats per model ("Trial use only — do not submit personal or confidential data"), default money/customer coworkers to paid or local models, and keep OpenCode's MIT LICENSE in the bundle.
7. **Trust and sustainability story.** Roo Code (2.1M installs) and Coworker (10.8k★) died; OpenBot relicensed Apache→PolyForm-NC at 0.1.12; Cursor sold to SpaceX; Anthropic moved Cowork cloud-only; Gemini CLI dropped free tiers. A written license-stability pledge (Apache-2.0 forever for the core), a trademark policy (Open WebUI shows why), and a visible monetization plan (OpenWork: Team $10/user; AnythingLLM: hosted $50; Cursor India: ₹649; Sahayak: ₹99–199) will beat vague "free forever".
8. **Telemetry precision.** Claude Code ships multiple on-by-default channels; AnythingLLM and Cherry are opt-out; OpenBot, Paseo, Msty, Open WebUI desktop claim none. "No telemetry" is table stakes in this set — publish an explicit what-leaves-the-machine table to make it credible.
9. **Copy proven primitives instead of reinventing:** Goose's four-mode permission ladder; OpenClaw's state-dir env conventions and "same-host, never copied" login rule; OpenHands' credential-path table; Cline's import of Claude Code/Codex sessions; CopilotKit's "decided before, recorded after" audit framing; Eigent's note that "Scheduled runs require [the app] to stay open" (decide early whether Sahkarmi schedules need a background service).
10. **Watch list (quarterly):** OpenBot (10 releases/5 days; if it adds approvals + Indic + relicenses, it is a direct clone), OpenClaw (if it ships a safe-defaults non-technical mode), OpenWork (SOC 2, Windows signed, Team tier), Meta Muse for Small Business geography/Windows, Zoho Zia Agents GA pricing, Antigravity ToS changes.
