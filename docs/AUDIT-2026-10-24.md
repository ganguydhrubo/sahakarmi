## Strengths worth preserving

- Honest product documentation culture (PRIVACY, SECURITY, approvals caveat) and a hardened Electron setup.
- Fake-provider test harness that lets contributors run the suite with no AI account.
- Tag-driven release pipeline with checksums, SBOM and provenance; auto-update works.
- Local-first architecture with reuse of existing CLI logins; bundled free runtime.
- Bilingual, self-hosted, tracker-free website with an automated live verification job.
